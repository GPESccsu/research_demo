# 全局搜索功能使用说明

## 功能概述

全局搜索功能可以在整个 SciFlow 系统中快速查找内容，包括文献、素材、实验记录和写作草稿。

## 使用方式

### 1. 搜索入口
在顶部导航栏右侧找到搜索框，输入关键词后按 **Enter** 键开始搜索。

### 2. 搜索范围

全局搜索会在以下模块中查找：

#### 📚 文献（知识库）
- 标题
- 作者
- 期刊名称
- 标签

#### 📖 阅读素材
- 标题
- 内容
- 来源
- 标签
- 分类（前言素材、实验方法、图片素材、结果讨论）

#### 🧪 实验记录
- 标题
- 描述
- 样品编号

#### ✍️ 写作草稿
- 草稿内容

### 3. 搜索结果

搜索结果页面会显示：
- **总结果数**：在顶部显示找到的总条目数
- **分类展示**：按模块分组显示结果
- **快速导航**：每个分类都有"前往XX"按钮，可以直接跳转到对应模块

### 4. 结果操作

- **查看详情**：点击任意结果卡片查看详细信息
- **前往模块**：点击"前往XX"按钮跳转到对应功能模块
- **清除搜索**：点击"清除搜索"按钮返回之前的页面

### 5. 搜索技巧

#### 关键词选择
- 使用具体的关键词，如"Co₃O₄"、"催化剂"
- 可以搜索作者名、期刊名
- 支持中英文混合搜索

#### 搜索示例
```
锌空气电池    → 查找所有相关文献和素材
Zhang         → 查找作者为 Zhang 的文献
实验方法      → 查找实验方法分类的素材
XRD          → 查找包含 XRD 的实验记录
```

## 搜索结果说明

### 文献结果
显示匹配的文献，包括：
- 标题
- 作者
- 期刊
- 年份
- 被引次数
- 标签

### 素材结果
显示匹配的素材，包括：
- 标题
- 内容预览（前150字）
- 分类标签
- 来源
- 标签

### 实验记录结果
显示匹配的实验记录，包括：
- 标题
- 时间
- 描述
- 样品编号

### 写作草稿结果
显示匹配的草稿，包括：
- 章节ID
- 内容预览（前200字）
- 更新时间

## 注意事项

1. **搜索是实时的**：输入关键词后按 Enter 立即搜索
2. **大小写不敏感**：搜索"zhang"和"Zhang"效果相同
3. **部分匹配**：搜索"催化"可以匹配"催化剂"、"电催化"等
4. **空搜索**：清空搜索框会自动清除搜索结果
5. **性能**：搜索在本地数据库中进行，速度很快

## 快捷键

- **Enter**：执行搜索
- **Esc**：清空搜索框（需要手动实现）
